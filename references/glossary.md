# Glossary (seed — expand with citations)

| Term | Meaning |
|---|---|
| PEA / Scoping | Preliminary Economic Assessment — early, conceptual, may use Inferred resources |
| PFS | Pre-Feasibility Study — narrowed options, mostly Indicated/Measured basis |
| FS / DFS / BFS | (Definitive/Bankable) Feasibility Study — detailed, reserve-backed |
| NI 43-101 | Canadian disclosure rule for mineral projects (Form F1 technical reports) |
| JORC Code | Australasian reporting code (Table 1 checklist, Competent Person) |
| QP | Qualified Person (NI 43-101) — responsible for sections of the report |
| Cutoff grade | Minimum grade (or NSR) for material to count as resource/reserve |
| NSR | Net smelter return — recoverable value per tonne after payabilities/charges |
| Strip ratio | Waste : ore tonnes (open pit) |
| Recovery | % of contained metal reporting to saleable product |
| CAPEX | Initial + sustaining capital; contingency reported separately |
| OPEX | Mining + processing + G&A per tonne; LOM total |
| AISC | All-in sustaining cost per payable unit (state by-product treatment) |
| NPV / IRR / payback | Net present value (state discount rate) / internal rate of return / years to pay back |
| M / I / Inf | Measured / Indicated / Inferred resources (rising geological confidence) |
| Prov / Prob | Proven / Probable reserves (modified M/I by mining/economic factors) |
